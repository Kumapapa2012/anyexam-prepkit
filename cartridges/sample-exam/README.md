# カートリッジ：サンプル試験

フレームワークでできることをひととおり示すための見本カートリッジ。
フレームワーク側の説明は[リポジトリルートの README](../../README.md) を参照。

素材（画像・音声・動画）はすべて自作で、外部の著作物を含まない。
自分の試験用カートリッジを作るときの雛形としてコピーして使える。

## 試験要綱

| 項目 | 値 |
|---|---|
| 合格ライン | 60% |
| 本番モード | 30問・60分 |
| 通常セッション | 10問 |

### セクションと本番出題数

| セクション | 本番 | 問題バンク |
|---|---|---|
| 単一選択問題 | 10問 | 20問 |
| 複数選択問題 | 10問 | 20問 |
| 画像問題 | 5問 | 10問 |
| 音声動画問題 | 5問 | 10問 |
| **合計** | **30問** | **60問** |

## 収録している問題の種類

「セクション」は出題の配分を決めるための区分であり、形式とは独立している。
たとえば画像問題セクションにも複数選択の問題が含まれる。

- **単一選択問題**：一般常識・理科・歴史・地理・IT・数学・国語などの分野混在
- **複数選択問題**：すべて「当てはまるものをすべて選べ」形式。正解の個数は問題文に明示
- **画像問題**
  - よく似た2枚の風景から、英文の説明に合う方を選ぶ（選択肢そのものが画像）
  - 図形の角度を求める（平行線と折れ線、円周角）
  - グラフ読み取り、フローチャートの追跡、並列回路、図形の対称性
- **音声動画問題**
  - ニュース映像を見て内容を答える
  - 英語2名の会話を聞いて内容を答える
  - 駅・店内アナウンス、週間天気予報の聞き取り

## ディレクトリ

```
cartridge.json      … 試験の定義
data/
  q-single.json     … 単一選択 20問
  q-multi.json      … 複数選択 20問
  q-image.json      … 画像問題 10問
  q-av.json         … 音声動画問題 10問
assets/             … 画像(SVG) 10点 / 音声(mp3) 5点 / 動画(mp4) 1点 + ポスター画像
tools/
  make_images.py    … SVG 画像を生成
  make_media.py     … 音声を合成し、動画を軽量化して取り込む
dist/               … ビルド成果物（gitignore）
```

問題は `section` フィールドで自分のセクションを直接指定している（分類ラベルファイルは不要）。

## 素材の再生成

```bash
python cartridges/sample-exam/tools/make_images.py
python cartridges/sample-exam/tools/make_media.py --news <元動画のパス>
```

- 画像はすべて Python が SVG を組み立てて出力する。街角の風景は同じ描画関数に
  信号の色・車の色・傘や犬の有無を渡して「よく似た2枚」を作っている。
- 音声は Windows の読み上げ（System.Speech、Zira と David の2声）で行ごとに合成し、
  0.6秒の間をはさんで ffmpeg で連結する。
- 動画は `--news` で渡した動画を 2MB 以下に再エンコードし、先頭付近からポスター画像を作る。
  収録済みの `news.mp4` は架空のニュース映像（登場人物・報道内容とも架空）。
  再生成する場合は `--news` に自分の動画を指定すること。

いずれも ffmpeg が必要。音声合成は Windows 環境でのみ動作する。

## ビルド

```bash
python core/tools/build_cartridge.py cartridges/sample-exam
```
