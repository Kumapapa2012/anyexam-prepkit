User Guide

anyexam-prepkit
ユーザーガイド

試験の練習問題をスマホで繰り返し解くための練習アプリ、その使い方の案内です。アプリを開くところから、成績の読み方、毎日の練習の組み立て方までをひと通り扱います。

💡
まずはここから

どんなアプリなのかを画面写真つきで知りたい方は 01. このアプリでできること へ。すでに使い始めている方は、必要な章に直接飛んでください。

✦
🚀 その場で試せるデモサイトがあります

サンプル試験のデモを開く — 登録不要、「デモ開始」ボタン 1 つですぐ問題を解けます。このガイドの画面写真と同じ 60 問が入っているので、読みながら実際に触ってみてください。

お試し用なので成績は残りません。本格的に練習するときは、配布元から渡された URL を使ってください。

このガイドについて

このガイドはアプリを使って勉強する人に向けて書かれています。問題を解き、間違いを潰し、成績の伸びを確かめる——その一連の流れを迷わず回せるようになることがゴールです。

✦
アプリを用意する側の方へ

自分の試験用に問題を差し替えたい、サーバーに立てて複数人で使いたい、といった話は 開発者向け Wiki にまとまっています。カートリッジの作り方・ビルド・デプロイ・運用はそちらを参照してください。

画面写真について

このガイドに載っている画面写真は、すべて同梱のサンプル試験（全 60 問）のものです。

⚠️
数字は試験ごとに違います

問題数・1 セッションの問題数・本番モードの制限時間・合格ラインは、あなたが使う試験の設定によって変わります。数字そのものではなく、画面の使い方として読んでください。
